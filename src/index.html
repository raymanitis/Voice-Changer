How it works

  1. Install the free VB-Audio Virtual Cable once, then restart VoxShift.
  2. Pick your real microphone above.
  3. Turn on Use in all apps and press Start.
  4. Apps set to the Default mic now get your changed voice. Apps with a fixed mic: choose CABLE Output.
